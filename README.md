# PreSiBO v1 Interface

PreSiBO is a searchable interface for Alzheimer disease multi-omics, polygenic risk score, network, and drug-repurposing results. It brings related evidence together so researchers can move from a gene or compound to the available target, network, and drug records in a consistent format.

The deployed interface is available at [presibo-v1.vercel.app](https://presibo-v1.vercel.app/).

## Scope

- **Target** presents predictor, biomarker, outcome, differential-expression, and quantitative-trait-locus results.
- **Network** presents network membership, gene profiles, and polygenic risk score associations.
- **Drug** presents drug, target, clinical-trial, and repurposing evidence.

This repository contains the interface software only. Production data, database exports, credentials, and the archival demonstration fixture are not distributed from this branch.
